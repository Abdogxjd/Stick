# 🎬 Stick Nodes Web - محرك تحريك ثنائي الأبعاد للموبايل

## 📋 نظرة عامة

**Stick Nodes Web** هو تطبيق ويب احترافي مخصص للموبايل لإنشاء رسوم متحركة ثنائية الأبعاد (2D Animation) باستخدام نظام الهياكل العصوية (Stick Figures). يُعد نسخة مطورة من تطبيق Stick Nodes Pro مع إضافة ميزات ذكاء اصطناعي واستيراد شخصيات من الصور.

## ✨ الميزات الرئيسية

### 🎨 نظام الهياكل العصوية
- أنواع متعددة من العقد والشرائح (مستطيل، دائري، مثلث، شبه منحرف)
- نظام ربط هرمي (Hierarchical Rigging)
- خصائص متقدمة (لون، سماكة، شفافية، تمدد)
- مكتبة هياكل محلية قابلة للتوسيع

### 🎬 نظام التحريك
- تحريك إطار بإطار (Frame-by-Frame)
- بيننة تلقائية (Tweening) مع أنواع Easing
- قشرة البصل (Onion Skinning)
- جدول زمني تفاعلي (Timeline)

### 📸 استيراد الشخصيات من الصور (ميزة حصرية)
- اختيار صورة من معرض الجهاز
- تحديد العظام والنقاط على الصورة
- إنشاء هيكل عصوي تلقائي من الصورة
- دعم الشفافية والطبقات

### 🤖 مساعد الذكاء الاصطناعي (AI Agent)
- دعم Google Gemini API
- وضع دردشة مباشر داخل التطبيق
- وضع عميل خارجي مع نسخ/لصق
- Function Calling بتنسيق JSON
- استمرارية المحادثة بين الجلسات

### 💾 حفظ المشاريع
- حفظ محلي (LocalStorage/IndexedDB)
- تصدير/استيراد ملفات المشاريع
- معاينة مصغرة للمشاريع
- حفظ تلقائي

### 📤 التصدير
- صيغ متعددة (GIF, MP4, PNG Sequence)
- إعدادات الجودة والدقة
- Wake Lock للتصدير في الخلفية
- معاينة قبل التصدير

## 🏗️ هيكل المشروع

```
src/
├── components/          # مكونات React
│   ├── canvas/         # مكونات الكانفاس
│   ├── timeline/       # مكونات الجدول الزمني
│   ├── sidebar/        # الأشرطة الجانبية
│   ├── modals/         # النوافذ المنبثقة
│   └── ui/             # مكونات UI عامة
├── engine/             # محرك الرسوم
│   ├── canvas/         # Canvas 2D Engine
│   ├── nodes/          # نظام العقد
│   ├── animation/      # نظام التحريك
│   └── export/         # نظام التصدير
├── stores/             # إدارة الحالة (Zustand)
├── hooks/              # React Hooks
├── types/              # أنواع TypeScript
├── utils/              # دوال مساعدة
└── ai/                 # نظام الذكاء الاصطناعي
```

## 🛠️ التقنيات المستخدمة

- **React 19** - إطار العمل
- **TypeScript** - اللغة البرمجية
- **Tailwind CSS** - التصميم
- **Zustand** - إدارة الحالة
- **HTML5 Canvas** - الرسم والتحريك
- **MediaRecorder API** - تسجيل الفيديو
- **IndexedDB** - التخزين المحلي
- **Gemini API** - الذكاء الاصطناعي

## 🚀 التشغيل
